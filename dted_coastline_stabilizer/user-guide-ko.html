DTED Coastline Stabilizer 한글 사용법

QGIS에서 고도 자료(DTED)에 해안선을 겹쳐 보고, 검토한 해역의 고도를 0 m 또는 −50 m로 저장할 수 있습니다. 탭과 버튼은 화면에 표시되는 이름으로 안내합니다.

  • 예제로 시작하기
  • 설치
  • 자료 불러오기
  • 미리보기와 편집
  • 결과 저장
  • 위성사진으로 해안선 생성

예제로 시작하기

  1. Inputs 탭의 Browse…를 눌러 프로젝트의 example 폴더에서 Source DTED에 dem-0.tif, Shoreline Shapefile에 shoreline.shp, RGB Imagery Folder에 imagery 폴더를 지정합니다. Check Inputs and Load Map을 누릅니다.
  2. Map Editing 탭에서 Sea Seed를 누른 뒤 지도 왼쪽 바다 안쪽을 한 번 클릭합니다. Land Seed를 눌러 오른쪽 육지와 왼쪽 바다에 있는 섬 안쪽에도 각각 기준점을 하나씩 추가합니다.
  3. Analysis and Export 탭의 Output Sea Elevation에서 −50 m를 선택하고 Preview DTED Elevation을 누릅니다. 분류가 모호한 곳은 미리보기와 편집을 따라 확인합니다.
  4. 결과를 확인한 뒤 Validate and Export…을 누르고 저장할 위치를 선택합니다. 새 결과 폴더의 elevation.tif가 보정한 고도 파일입니다.

해안선 파일 없이 컬러 위성사진부터 시작하려면 위성사진으로 해안선 생성을 따라 하세요.

1. QGIS에 설치하기

  1. QGIS 4.2.2에서 Plugins → Manage and Install Plugins… → Install from ZIP을 엽니다.
  2. dted_coastline_stabilizer.zip을 압축 해제하지 않은 상태로 선택하고 Install Plugin을 누릅니다.
  3. 패널을 닫았다면 Plugins → DTED Coastline Stabilizer → DTED Coastline Stabilizer에서 다시 엽니다. 패널 상단의 한글 사용법 또는 같은 메뉴의 Korean User Guide로 안내서를 열 수 있습니다.

QGIS 메뉴를 영어로 표시하려면 Settings → Options → General에서 Override System Locale을 켜고 User interface translation을 American English로 바꾼 뒤 QGIS를 다시 실행합니다.

위성사진으로 해안선 생성

Satellite 탭에서는 RGB GeoTIFF만으로 해역과 해안선을 만들 수 있습니다. 처음에는 example/imagery/synthetic-rgb.tif로 연습해 보세요.

  1. Load RGB GeoTIFFs…에서 영상 파일을 고릅니다. 여러 타일에 걸친 구역은 파일을 함께 선택합니다.
  2. Draw Area of Interest를 누릅니다. 육지와 외해가 모두 들어가는 구역의 꼭짓점을 왼쪽 클릭으로 찍고 오른쪽 클릭으로 마칩니다. 넓은 구역은 분석 해상도를 자동으로 낮추므로 작은 해안 지형의 세부 묘사가 줄어들 수 있습니다.
  3. Add Land Sample와 Add Offshore Sample를 눌러 경계에서 떨어진 대표 지점을 각각 찍습니다. 색과 질감이 다른 육지나 외해가 보이면 표본을 추가한 뒤 Generate Sea Area and Coastline을 누릅니다.
  4. 지도에 표시된 해역을 살펴보고, Review Areas 목록을 클릭해 갯벌·하구 후보나 영상 공백으로 이동합니다. Edit Coastline Vertices을 누르면 QGIS 정점 도구로 해역의 가장자리를 수정할 수 있습니다. 해안선도 함께 갱신됩니다.
  5. Save Coastline and Sea Shapefiles…을 누르면 선택한 위치 아래의 새 폴더에 선과 면이 각각 저장됩니다. 두 SHP의 .shx, .dbf, .prj 파일을 같은 폴더에 둡니다. 저장한 SHP를 QGIS 지도에 끌어다 놓아 열 수 있습니다.
  6. 최종 해역을 Approve Sea Area for DTED로 선택합니다. Inputs에서 Source DTED를 고르고 Check Inputs and Load Map을 누릅니다. Analysis and Export에서 0 m 또는 −50 m를 선택해 미리 보거나 저장합니다. 선택한 폴리곤 안의 유효한 DTED 픽셀에만 지정 고도가 적용됩니다.

2. 자료 불러오기

Inputs 탭에서 각 항목의 Browse…를 눌러 파일이나 폴더를 선택합니다. 처음에는 프로젝트의 example 폴더에 있는 예제로 연습할 수 있습니다.

화면 항목선택할 자료
Source DTED원본 고도 파일. 예제는 dem-0.tif이며, 기존 해역 고도가 −50 m인 예제는 dem--50.tif입니다.
RGB Imagery Folder컬러 GeoTIFF가 들어 있는 폴더. 예제는 imagery 폴더이며 영상 없이 작업할 경우 비워 둡니다.
Shoreline Shapefile선으로 그려진 해안선 파일. 예제는 shoreline.shp입니다.
Validation Reference결과와 비교할 참조 고도 파일. 참조 자료가 있을 때 선택합니다.
Verified Sea Areas이미 해역으로 확인한 구역을 담은 폴리곤 파일이 있을 때 선택합니다.

Check Inputs and Load Map을 누릅니다. 해안선의 좌표계를 확인하라는 메시지가 나오면 자료 제공자가 확인한 좌표계 코드를 Shoreline CRS에 넣고 Confirm Shoreline CRS를 누른 뒤 입력 검사를 다시 실행합니다. Working CRS (meters)는 거리 계산에 사용하는 좌표계로 기본값은 EPSG:32652입니다.

3. 미리 보고 해안선 수정하기

  1. Analysis and Export 탭에서 Input Sea Elevation을 고릅니다. 기존 자료의 바다 고도를 알면 0 m 또는 −50 m를, 모르면 Auto Detect를 선택합니다. 기존 고도를 판정에 참고하지 않으려면 Disabled를 선택합니다.
  2. Output Sea Elevation에서 결과에 쓸 바다 고도를 고르고 Preview DTED Elevation를 누릅니다. 새 작업의 −50 m 결과는 해안에서 바다 쪽으로 12 m에 걸쳐 부드럽게 내려갑니다. Transition Width에서 폭을 바꾸거나 0 m로 설정할 수 있습니다. Validation Reference를 불러오면 참조와 결과에 같은 고도 표시 범위를 적용합니다.
  3. Map Editing 탭의 Review Areas에서 항목을 클릭해 확인이 필요한 구역으로 이동합니다. Inspect Elevation을 누르고 지도 위 지점을 클릭하면 원본 고도를 볼 수 있습니다. 미리보기가 있으면 결과 고도와 분류도 표시됩니다.
  4. Land Seed나 Sea Seed를 누르고 확실한 육지나 바다의 안쪽을 클릭하면 분류 기준점을 추가할 수 있습니다. 예제에서는 서쪽 바다, 동쪽 육지, 바다에 떨어진 섬에 각각 기준점을 찍어 봅니다.
  5. 해안선을 바꾸려면 Start DTED Editing을 누릅니다. Edit Vertices로 선의 점을 옮기거나 추가·삭제할 수 있습니다. Replace Segment는 같은 해안선 위의 두 지점 사이를 다시 그리고, Add Shoreline은 새 선을 그립니다. 점을 왼쪽 클릭으로 찍고, 오른쪽 클릭으로 마칩니다. 그리기를 취소하려면 Esc를 누릅니다.
  6. 특정 구역을 직접 분류하려면 Force Land(육지), Force Sea(바다), Keep Original(원본 고도 유지) 중 하나를 선택하고 지도에서 구역을 그립니다. 세 점 이상 찍은 뒤 오른쪽 클릭으로 닫습니다. 구역이 겹치는 곳에는 가장 최근에 그린 구역의 설정이 적용됩니다.
  7. 활성 편집 레이어에서 Undo와 Redo를 사용할 수 있습니다. 수정이 끝나면 Preview DTED Elevation를 다시 눌러 결과를 확인합니다.

4. 결과 저장하기

  1. Analysis and Export에서 Export Format을 선택하고 Validate and Export…를 누릅니다. 미리보기와 내보내기는 래스터 타일을 여러 CPU 코어로 나눠 처리합니다. GeoTIFF는 원본 격자를 유지합니다. DTED 레벨을 선택하면 최근접 이웃 방식으로 변환한 WGS 84 1도 타일도 함께 저장됩니다. 결과는 선택한 위치의 coast- 폴더에 저장됩니다.
  2. 지도에서 결과가 보이지 않으면 QGIS 레이어 목록에서 Output Elevation, Sea Mask 또는 Changed Pixels를 켭니다.
  3. 수정한 해안선만 따로 저장하려면 Map Editing → Save Edited Shoreline…에서 GeoPackage(.gpkg)로 저장합니다. 이후 작업을 이어가려면 QGIS 프로젝트(.qgz)도 저장하고, 프로젝트가 참조하는 입력 파일과 작업 파일을 같은 위치에 둡니다.
결과 파일내용
elevation.tif해역 고도를 반영한 GeoTIFF
.dt0, .dt1, .dt2DTED 레벨을 선택했을 때 함께 저장되는 표준 DTED 타일
sea-mask.tif육지 1, 바다 2, 미확정 3, 원본 유지 4, 자료 없음 255
changed-pixels.tif원본에서 고도가 바뀐 픽셀의 위치
coast.gpkg자동·수정 해안선, 검토 구역, 분류 구역, 기준점 및 편집 기록
settings.json, statistics.json실행 설정과 변경 픽셀 수, 미확정 면적 등 처리 통계
